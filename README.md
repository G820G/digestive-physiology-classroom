# 食物的旅程 · 消化与吸收交互课堂

一个用于中文生理学教学的本地网页，选用 [ashemag/human-atlas](https://github.com/ashemag/human-atlas) 中的 BodyParts3D 真实三维解剖素材。

## 直接打开课堂

优先使用交付的 `食物的旅程-消化与吸收-便携版.html`：单文件已内嵌三维模型、脚本、样式及素材署名，复制到其他电脑后可用支持 WebGL 的现代浏览器打开，无需安装 Node.js 或 Python。完整署名与软件许可可在页面底部的说明窗口离线查看。

电脑端按 1920×1080 的 16:9 演示画布设计，随窗口等比缩放；28px 为该设计画布的正文基准字号。模型栏宽约 1062px，占主内容宽度约 57%。页面保持单屏，左侧目录和右侧讲解独立滚动，底部七站卡片完整展示。窗口宽度小于 1000px 时切换为手机纵向布局，保留 28px 正文，结构目录和步骤卡片可横向滑动。

以下为源码项目的启动方式：

Windows 下双击 `打开课堂.cmd`。脚本使用已安装的 Node.js 或 Python，在本机启动网页并打开浏览器。保持启动窗口运行；关闭窗口即停止服务。已包含构建后的 `dist`，启动不需要 npm 安装或联网下载素材。

也可以在本目录手动运行：

```sh
node serve.mjs
```

或：

```sh
python serve.py
```

默认地址为 http://127.0.0.1:8765 ，被占用时自动尝试后续端口。源码项目的 `dist/index.html` 需通过本地服务器加载分离的模型文件；便携单文件 HTML 已将模型内嵌。浏览器需支持 WebGL。生产网页使用本地字体回退，不请求外部字体或 CDN。

## 课堂功能

- **结构探索**：自由旋转、缩放、平移；切换正面、侧面、背面；点选器官、聚焦、单独观察；切换人体轮廓和结构标签。
- **七站消化旅程**：口腔 → 咽与食管 → 胃 → 十二指肠 → 空肠与回肠 → 大肠 → 直肠与肛门。每站包含机制、消化液、关键特点、课堂思考与参考答案。
- **演示控制**：逐步切换、自动播放、暂停，支持 0.5× / 1× / 1.5× / 2× 速度。每站默认 12 秒。动画仅表示教学步骤，不表示真实消化时长。
- **辅助消化器官**：肝、胆囊与胆道、胰，可分别观察和讲解。
- **喉部结构**：新增甲状软骨与会厌独立模型；在目录选择后自动放大，支持旋转和单独观察，附吞咽与气道保护讲解。选中会厌时甲状软骨半透明显示。
- **呼吸道入口与气管上段**：加入环状软骨、左右杓状软骨、左右声韧带与气管源模型；气管只显示邻近喉部的一小段。蓝色喉腔与喉入口轮廓为半透明教学示意，便于和后方食管对照。
- **四阶段吞咽演示**：点击顶部“吞咽演示”，查看“呼吸准备 → 关闭气道 → 食团通过 → 恢复呼吸”。演示喉向上、向前移动，会厌翻转，食团从喉入口旁侧绕过并进入后方食管，以及会厌复位。可播放、暂停、重置、点击阶段或拖动进度条；全程约 16 秒，为刻意放慢的教学节奏。
- **食物示意**：保留柔和的金色移动光团，移除固定发光轨迹与轨迹粒子；点光源强度由 1.25 降至 0.18，光团不再使用叠加混合发白。
- **吸收机制**：糖类、蛋白质、脂肪的消化产物、跨上皮转运与血液/淋巴去向。
- **授课辅助**：全屏专注、中文搜索、课堂提问、手机布局。

鼠标左键拖动平移，右键拖动旋转，滚轮缩放；左键单击器官查看讲解。触屏单指旋转，双指缩放或平移。左右方向键切换步骤，空格播放/暂停，`/` 聚焦查找框（桌面布局）。

吞咽模式中，左右方向键将进度前后移动 5%，空格控制播放/暂停；进度条获得焦点后可用其原生方向键细调。金色表示食团，蓝色表示气道，棕色表示后方食管；不会显示白色食物轨迹。

## 修改与构建

需要 Node.js 20.19+ 或 22.12+：

```sh
npm ci
npm run dev
```

开发地址：http://127.0.0.1:5173

```sh
npm run build
```

产物位于 `dist/`，可部署至支持静态文件的网站服务。资源使用相对路径，可放在子目录。

主要文件：

- `src/content.ts`：教学正文、七站顺序、三类营养吸收机制。
- `src/main.ts`：界面与演示控制。
- `src/scene.ts`：三维模型、镜头、标签及食物路径。
- `src/swallow.ts`：喉部教学场景、会厌旋转、喉上提、食团和气流。
- `src/swallow-motion.ts`：吞咽四阶段正文与连续运动时序。
- `src/style.css`：界面与响应式样式。
- `public/models/`：筛选后的模型，共约 3.3 MB；121 个源网格（120 个结构及 1 个人体外形），148,864 个三角形，保留源 ID。
- `public/ATTRIBUTION.md`：模型来源、许可与适配说明。

## 教学边界与署名

三维模型是成人男性参考解剖，未完整呈现咽、肛管与微观结构。路径和吸收图为教学示意，未按真实时间或比例绘制。七步用于组织讲解，真实消化过程连续并相互重叠。

吞咽演示保留源模型几何，并用简化的入口轮廓、腔道、关闭面、位移和旋转表现功能。食团显示一条旁侧通过路线，真实食团的形变与两侧分流未模拟。会厌并非唯一屏障：喉前庭和声门关闭、喉上提及吞咽性呼吸暂停共同保护气道。
